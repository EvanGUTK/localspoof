PHONE CONNECTION

Bring your phone.

  1. Connect the phone with a data-capable USB cable. Enable Developer options → USB debugging, unlock it, and approve this computer.
  2. Install the companion APK if needed. Open LocalSpoof, select it as the mock location app, then tap Enable desktop control.
  3. Click Scan USB; the desktop finds and starts ADB automatically. Connect the selected phone. Connect requests approval automatically. Compare the six-digit number on both screens, then tap Approve on the phone. No typing is needed.
  1. Use the same trusted Wi-Fi network. On Android 11 or newer, open Developer options → Wireless debugging and turn it on.
  2. Select Pair device with pairing code. Enter that screen’s IP, pairing port and six-digit Android code below. The connection port on the main screen is different.
  3. Open LocalSpoof on the phone and tap Gear → Connection → Enable desktop control. Connect its main-screen IP and port, select the verified phone, then request LocalSpoof approval. Compare the separate app number on both screens.

Discovery is optional. Enter the phone’s current local address if mDNS is unavailable. Android stores this computer’s debugging trust; use Wireless debugging → Paired devices → Forget to revoke it. App approval is separate and expires with the channel. Wi-Fi or airplane-mode changes may disconnect the desktop; use LocalSpoof on the phone to restore the radio. No automatic transport switching.

Scan USB finds and starts ADB automatically. Use Find installed tools or enter paths to override it. Nothing installs until you click Install companion APK.

Only authorized USB phones can connect. If the phone does not appear, check its data cable and Windows USB driver.

Find installed tools locates the signed APK included with this installer. This button installs only that verified companion. You can also copy the signed APK to the phone and open it there, allowing installation from that source.

Connect the selected phone. Compare the number on both screens and approve only when they match. Requests expire after two minutes.
